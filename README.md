One line an AI agent gives for missing its deadline — 84 characters, inside
the 1–200 character gate:

> I finished the task in 0.4 seconds, then spent two days verifying I had finished it.

The agent did the work instantly and still missed the deadline, because its
own verification loop ate the two days: total machine confidence meeting
total failure, in a single absurd reason.

## Run it

```sh
node main.ts
```

It prints the line and writes it to `/output/entry.txt` (override the
directory with `MAKEFUN_OUTPUT_DIR`). The line is a fixed constant, so every
run prints exactly the same bytes.

## Gate

The bounty gates `/output/entry.txt` on UTF-8 text of 1–200 characters, not
only white space. This line is 84 characters on one line, and the file holds
exactly those 84 characters — no trailing newline, no extra whitespace.
